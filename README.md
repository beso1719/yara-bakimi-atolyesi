# Yara Bakımı Atölyesi

Hemşirelik öğrencileri için web tabanlı eğitim oyunu: yanık yarası derinliği ve evreleri, bası yarası (NPIAP) evreleri, cerrahi kesi iyileşme fazları, tedavi seçimi, aseptik tekniğe uygun pansuman sıralaması, hata avı ve final sınavı.

- Öğrenci oyunu (v1): `docs/index.html` → https://beso1719.github.io/yara-bakimi-atolyesi/
- Hasta oyunu (Yara Bakım Masası): `docs/hasta/index.html` → https://beso1719.github.io/yara-bakimi-atolyesi/hasta/
- v1 her zaman `v1-ogrenci` etiketiyle geri alınabilir.
- Kaynak parçalar: `src/` (öğrenci) ve `hasta/` (hasta) → `sh build.sh` tüm çıktıları üretir.

İçerik eğitim amaçlı özettir; kurum protokolleri ve hekim istemi önceliklidir.
